# PavelCore
PavelCore — Coffre-Fort numérique &amp; Second Brain PavelCore est une application web ultra-sécurisée et moderne conçue sous Streamlit pour la gestion de connaissances et l'organisation personnelle. Véritable coffre-fort numérique, elle offre un espace dédié pour centraliser, structurer et sécuriser l'ensemble de vos ressources essentielles.
